# EL Couch Academy — Football Academy System

A management system for football academies to track players, training schedules, matches, and performance.

## 📋 Features
- Player profiles and registration
- Training schedule management
- Match tracking and results
- Performance analytics
- Coach and admin dashboard

## 🛠️ Tech Stack
- Python
- Streamlit

## 🚀 Run Locally
```bash
git clone https://github.com/mekhail22/EL-couch-academy.git
cd EL-couch-academy
pip install -r requirements.txt
streamlit run app.py
